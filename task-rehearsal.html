Task Rehearsal

Give the user a small everyday task and show where the environment creates unnecessary decision work.

TASK Bathroom

Find and use the bathroom safely at night.

This is an environment interaction exercise (not a cognitive test).

BEFORE CHANGE

Try the task

The task contains multiple visual cues. Notice which elements compete for attention.

  1. Find the entrance

    Doorway is not strongly distinguished.

  2. Identify the fixture

    Fixture and background are visually similar.

  3. Ignore competing information

    Visual clutter adds another decision.

WHAT THE ENVIRONMENT IS ASKING

  • 4

    ambiguous decision points

  • 3

    similar visual cues

  • 1

    clear landmark

Key Learning

The task can become easier when the environment presents clearer cues.
